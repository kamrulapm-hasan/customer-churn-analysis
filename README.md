# Customer Churn Analysis

## Project Overview

This project analyzes customer activity, subscriptions, and cancellations using Python and Pandas.

The objective is to explore customer behavior and identify patterns related to customer cancellations.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Analysis

The project covers:

- Data cleaning and preparation
- Combining and exploring datasets
- Customer and subscription analysis
- Cancellation analysis
- Descriptive statistics
- Data visualization
- Business-oriented interpretation

## Dataset

The datasets used in this project were provided as part of a university course and are not included in this public repository.

## Project File

- `customer_churn_analysis.ipynb` — Complete analysis and Python code
